# 26.x 数据包地形生成（density_function 路线）

> 这是**数据包级**的改地形方式，和同目录 `26.x-自定义世界生成器.md`（**代码级** chunk generator）
> 是两条不同的路，可以配合用。
> 数据包级不用写 Java、改完重启就生效，适合先快速试形态；定下来后再移到代码里。

---

## 0. ⚠️ 第一原则：版本会变，别抄配置，去当前版本的 jar 里读

**Minecraft 的 worldgen 数据格式几乎每个版本都在动**。同一个字段：
- 1.16 有 `data/<ns>/dimension/<name>.json` 定义维度 → **26.1 里这个目录没了**
- 1.18 引入 `density_function` 体系 → 之前是 `noise_settings` 里直接写噪声
- 26.1 把维度定义搬进了 `world_preset`

**所以"学地形生成"的正确姿势不是存一份配置模板，而是掌握"怎么从当前版本里读出真相"**：

```bash
# 一切以当前版本的客户端/服务端 jar 为准
python - <<'PY'
import zipfile, os, json
z = zipfile.ZipFile(os.path.expanduser(
    "~/.gradle/caches/neoformruntime/artifacts/minecraft_26.1_client.jar"))
# 看 worldgen 数据有哪些类别、各多少个 → 立刻知道当前版本的"地形词汇表"
for n in sorted({x.split("/")[3] for x in z.namelist() if x.startswith("data/minecraft/worldgen/")}):
    print(n)
PY
```

**然后**：拿原版自带的预设**当对照样本**（下面 §3 那张表就是这么来的），
照搬它的**结构**、只改**参数** —— 这是最稳的借鉴方式（§4 实测）。

## 1. 26.1 的 worldgen 数据结构（实测）

`data/<ns>/worldgen/` 下的类别与数量（原版）：

| 目录 | 数量 | 作用 |
|---|---|---|
| `noise_settings` | **8** | **地形总定义**（高度范围/海平面/密度函数树/表层规则）|
| `density_function` | 42 | 密度函数（可嵌套、可互相引用）|
| `noise` | 64 | 噪声参数（`firstOctave` + `amplitudes`）|
| `biome` | 66 | 生物群系 |
| `configured_feature` / `placed_feature` | 222 / 259 | 装饰（树、矿、花…）|
| `structure` / `structure_set` / `template_pool` | 35 / 21 / 245 | 结构 |
| `world_preset` | 7 | **世界预设（含维度定义）** |
| `flat_level_generator_preset` | 10 | 超平坦预设 |

### ⭐ 维度定义搬进了 `world_preset`

```jsonc
// data/minecraft/worldgen/world_preset/normal.json
{
  "dimensions": {
    "minecraft:overworld": {
      "type": "minecraft:overworld",        // ← dimension_type
      "generator": {
        "type": "minecraft:noise",
        "biome_source": { "type": "minecraft:multi_noise", "preset": "minecraft:overworld" },
        "settings": "minecraft:overworld"   // ← 指向 noise_settings！
      }
    },
    "minecraft:the_end": { ... },
    "minecraft:the_nether": { ... }
  }
}
```

**`generator.settings` 就是"地形总开关"** —— 改地形 = 改它指向的 `noise_settings`。

### noise_settings 的字段

| 字段 | 例（overworld） | 说明 |
|---|---|---|
| `noise.height` / `min_y` | 384 / -64 | **世界高度范围**（`size_horizontal`/`size_vertical` 是噪声网格粒度）|
| `sea_level` | 63 | 海平面。设成 -64 就没有海 |
| `default_block` | stone | 固体默认方块 |
| `default_fluid` | water | 流体默认方块 |
| `aquifers_enabled` | true | 含水层。做特殊地形通常关掉 |
| `ore_veins_enabled` | true | 矿脉 |
| `legacy_random_source` | false | 老式随机源 |
| **`noise_router`** | — | **核心：一堆"用途名 → 密度函数"的映射** |
| `surface_rule` | — | 表层规则（草/沙/石）|
| `spawn_target` | — | 出生点条件 |

### `noise_router` 里的键（决定地形的一切）

| 键 | 作用 |
|---|---|
| **`final_density`** | **决定每一格是固体还是空气** ← 改地形主要动它 |
| `continents` / `depth` / `erosion` / `ridges` | 基础地形参数（大陆性/深度/侵蚀/山脊）|
| `temperature` / `vegetation` | 生物群系气候 |
| `barrier` / `fluid_level_*` / `lava` | 含水层 |
| `preliminary_surface_level` | 地表高度（`find_top_surface`）|
| `vein_*` | 矿脉 |

**判定规则**：`final_density > 0` → 固体，`≤ 0` → 空气。

## 2. density_function：有哪些算子（26.1 实测，从全部 42 个文件里统计）

| 类别 | 算子 | 用途 |
|---|---|---|
| 算术 | `add` `mul` `min` `max` `abs` `cube` `clamp` `quarter_negative` `half_negative` | 组合、翻转、钳制 |
| 常数 | `constant` | 直接给值 |
| 噪声 | `noise` `shifted_noise` `old_blended_noise` `weird_scaled_sampler` | 采样噪声 |
| 高度 | **`y_clamped_gradient`** | **按 y 做线性渐变 ← 做浮岛/分层的关键** |
| 曲线 | `spline` | 样条映射（高度→密度这类非线性关系）|
| 条件 | `range_choice` | 按输入范围选不同分支 |
| 引用 | 直接写字符串如 `"minecraft:overworld/depth"` | 引用另一个 `density_function/*.json` |
| 缓存 | `flat_cache` `cache_once` `cache_2d` `interpolated` | **性能**（`interpolated` 几乎必用）|
| 混合 | `blend_density` `blend_alpha` `blend_offset` | 区块边界平滑 |
| 特殊 | `end_islands` | 末地浮岛专用函数 |

### ⚠️⚠️ 噪声的"值域"必须先量，不能假设

**这是本次最大的坑。** 不同的噪声来源值域差一个数量级：

| 噪声 | amplitudes | 理论值域 |
|---|---|---|
| `cave_cheese` | [0.5, 1, 2, 1, 2, 1, 0, 2, 0] | **±9.5** |
| `temperature` | [1.5, 0, 1, 0, 0, 0] | ±2.5 |
| `vegetation` | [1, 1, 0, 0, 0, 0] | ±2.0 |
| `spaghetti_3d_1` | [1.0] | **±1.0** |

**`amplitudes` 之和 ≠ 实际范围**（实际通常更小、而且可能偏心），**必须实测**。

**症状**：把 `cave_cheese` 当 ±1 的噪声用（直接乘 0.5~1），
结果整片地形**全实心**（值恒为正）；改成除 9.5 归一，又可能**全空**（值实际偏小）。

**正确做法**：**照搬原版已经调好的结构**（见 §3/§4），别自己从零配一个噪声上去。

## 3. 原版 8 套 noise_settings 的参数对照（最好的借鉴源）

| 预设 | height | min_y | sea_level | aquifers | legacy_random |
|---|---|---|---|---|---|
| `overworld` | 384 | -64 | 63 | true | false |
| `amplified` | 384 | -64 | 63 | true | false |
| `large_biomes` | 384 | -64 | 63 | true | false |
| `nether` | — | — | — | — | — |
| `end` | — | — | — | — | — |
| **`floating_islands`** | **256** | **0** | **-64** | **false** | **true** |
| **`caves`** | **192** | -64 | **32** | **false** | **true** |

**读出来的规律**：
- 想做"没有海的天空世界" → `sea_level` 设 -64、`aquifers_enabled` 关掉
- 高度范围由 `height`/`min_y` 决定（`floating_islands` 用的是老式 0~255）
- **`final_density` 的差异不在表层**：overworld/amplified/large_biomes 的 `final_density`
  结构**完全一样**（它们靠上游的噪声参数区分）—— 所以别指望改一处就换风格

## 4. 案例：从零改出一个浮岛世界（实测跑通）

**原版 `floating_islands` 的 `final_density` 化简后等价于**：

```
密度 = squeeze(0.64 × interpolate(
           -0.234375
         + 下梯度(0→40, 0→1)
           × ( 0.234375
             + (-23.4375
               + 上梯度(150→300, 1→0)
                 × (23.4375 + old_blended_noise) ) ) ))
```

**核心就是"噪声 × 下衰减 × 上衰减"**：
- `y_clamped_gradient` 做上下衰减 → 只有中间高度带才是实的 → **自然浮起来**
- 那两个 `±23.4375` 是**值域补偿**（`old_blended_noise` 是几十量级的量，不是 ±1）

**照搬结构、只改噪声频率就是我的浮岛**：
```jsonc
"final_density": {
  "type": "minecraft:squeeze",
  "argument": { "type": "minecraft:mul", "argument1": 0.64,
    "argument2": { "type": "minecraft:interpolated",
      "argument": { "type": "minecraft:add", "argument1": -0.234375,
        "argument2": { "type": "minecraft:mul",
          "argument1": {"type":"minecraft:y_clamped_gradient","from_y":0,"to_y":40,
                        "from_value":0.0,"to_value":1.0},
          "argument2": { "type": "minecraft:add", "argument1": 0.234375,
            "argument2": { "type": "minecraft:add", "argument1": -23.4375,
              "argument2": { "type": "minecraft:mul",
                "argument1": {"type":"minecraft:y_clamped_gradient","from_y":150,"to_y":300,
                              "from_value":1.0,"to_value":0.0},
                "argument2": { "type": "minecraft:add", "argument1": 23.4375,
                  "argument2": {
                    "type": "minecraft:old_blended_noise",
                    "smear_scale_multiplier": 4.0,
                    "xz_factor": 80.0, "xz_scale": 0.045,   // ← 原版 0.25，改小 = 特征更大
                    "y_factor": 160.0, "y_scale": 0.09      // ← 原版 0.25
                  }}}}}}}}}}
}
```

**只改了 `xz_scale` / `y_scale`**，就把浮岛的尺度改掉了 —— **这才是"借鉴"的正确姿势：
抄结构，改参数，别自创公式。**

### 另外两个实验（都验证成功）

**① 石板世界**（证明能控制高度）——`final_density` 直接换成：
```jsonc
{"type": "minecraft:y_clamped_gradient",
 "from_y": 63, "to_y": 65, "from_value": 1.0, "to_value": -1.0}
```
→ 实测**处处 y=63 的石头**，完全没有起伏 ✓

## 5. 实测踩坑

1. **覆盖率靠得住**：数据包**可以覆盖 `minecraft:overworld` 的 `noise_settings`**
   （`data/minecraft/worldgen/noise_settings/overworld.json`），不用改 `world_preset`。
   实验里就是这么干的。
2. **改完必须重启服务端**：worldgen 注册表只在世界加载时构建，`/reload` 无效（老坑，见 SKILL.md）。
3. **必须删世界重生成**：已生成的区块不会按新规则改写。删 `level.dat` + `dimensions/` 即可。
4. **`aquifers_enabled` 记得关**：否则"石板世界"里会被灌水、浮岛内部会灌水。
5. **`surface_rule` 也要换**：默认规则会在"固体上面"铺草/沙，做石头世界时
   换成 `{"type":"minecraft:block","result_state":{"Name":"minecraft:stone"}}`。
6. **别用 `cave_cheese` 当"±1 噪声"**（见 §2 的表），值域 ±9.5，会全实心。
7. **采样验证要取够密的点**：噪声特征尺寸 = 1/`xz_scale`，
   我最初用 `xz_scale 0.022`（≈45 格/周期）+ 7 个间隔几十格的采样点，
   结果全落在同一个周期里，误判成"地形没变化"。**能出图就出图，别靠采样点猜。**

## 6. 验证方法

```bash
# 1) 覆盖 noise_settings（见上）
# 2) 删世界重生成
rm -rf srv/world/level.dat srv/world/dimensions
# 3) 起服 → forceload → save-all
# 4) 出图（比采样点直观得多）
python 世界预览.py srv/world -o 地形.png --cx 0 --cz 0 --rad 110 --y0 30 --y1 120 --scale 1
```

**判据**：
- 石板实验 → 处处同一高度，无起伏
- 浮岛实验 → 有起伏、有侧面暴露、有洞口，且**明显区别于 overworld 的连绵地形**
